# Шаблоны отписей Храма Яо-ху

Скрипт, который добавляет готовые шаблоны отчетов и отписей в блогах. Шаблоны открываются в удобной форме, поддерживают предпросмотр и вставку готового BBCode в комментарий.

Скрипт работает на сайтах catwar.net и catwar.su через Tampermonkey.

## Что делает скрипт

- Добавляет кнопки шаблонов над полем комментария в блогах.
- Показывает разные наборы шаблонов в зависимости от страницы блога.
- Открывает форму с полями для даты, времени, ID участников, количества, ссылок и других данных.
- Показывает предпросмотр в виде BBCode или готового текста.
- Позволяет вставить текст в комментарий или скопировать его.
- Дает панель управления для создания, редактирования, дублирования и удаления шаблонов.
- Поддерживает поиск по шаблонам.
- Позволяет скачивать и загружать шаблоны файлом JSON.
- Хранит резервные копии данных в браузере.
- Запоминает последние введенные значения для некоторых полей.

## Как установить

Для работы скрипта вам понадобится специальное расширение для браузера — **Tampermonkey** (оно есть для Chrome, Firefox, Edge, Opera и Safari).

1. **Установите Tampermonkey:**
   *   Зайдите в магазин расширений вашего браузера и установите **Tampermonkey** (или перейдите на официальный сайт [tampermonkey.net](https://www.tampermonkey.net/)).
2. **Установите скрипт:**
   *   Нажмите на [эту ссылку](https://github.com/SpringChaos-boop/otchet-hram-yao-hu/raw/refs/heads/main/otchetnik.user.js).
   *   Откроется новая вкладка, и Tampermonkey предложит установить скрипт. Нажмите кнопку **«Установить»** (Install).
3. **Готово!** Теперь при заходе в нужный блог на CatWar панель появится сама.

## Первый запуск

1. Откройте панель управления внизу страницы или нажмите Alt+T.
2. В поле «Твой ID» впишите свой игровой ID.
3. Нажмите OK.
4. Перейдите в нужный блог.
5. Над полем комментария появятся кнопки с шаблонами.

## Как пользоваться

1. Нажмите на кнопку нужного шаблона.
2. Заполните поля формы: дату, время, ID участников, количество, ссылки и другие данные.
3. Проверьте предпросмотр. Его можно смотреть в виде BBCode или в виде готового текста.
4. Нажмите «Вставить», чтобы добавить текст в поле комментария.
5. Или нажмите «Копировать», чтобы забрать текст в буфер обмена.
6. Если передумали, закройте форму без вставки.

## Резервные копии и перенос

В панели управления есть раздел импорта и экспорта.

Там можно:

- скачать шаблоны файлом JSON;
- загрузить шаблоны из файла JSON;
- вывести код шаблонов в поле;
- вставить код шаблонов вручную;
- посмотреть резервные копии;
- восстановить нужную копию;
- очистить список копий.

Если данные браузера будут очищены, шаблоны могут пропасть. Поэтому удобно заранее сохранить файл с шаблонами.

## Горячая клавиша

Alt+T открывает и закрывает панель управления шаблонами.

## Хранение данных

Данные шаблонов хранятся в браузере. Скрипт не отправляет их на сторонние серверы.
